Q-Learning by Hand

Nov 18, 2026 · 4 min read

In my last post I wrote about the agent’s notebook, the Q-table. Now let’s use it. This is where the formula stopped looking scary for me. A mouse, a maze, and two steps of Q-Learning done by hand.

The setup

You’re a mouse in a tiny maze, and you always start at the same spot. You want the big pile of cheese in the bottom right corner, and you want to stay away from the poison.

  • The episode ends if you eat the poison, eat the big cheese, or take more than five steps.
  • Learning rate is 0.1.
  • Gamma, the discount rate, is 0.99.

The rewards:

+0
going to a spot with no cheese.
+1
going to a spot with a small cheese.
+10
going to the big pile of cheese.
-10
going to the poison, which means you die.
+0
if you take more than five steps.

The best path is right, right, down. That’s what Q-Learning should find on its own.

Before anything

The Q-table starts with a 0 in every cell. The mouse knows nothing. We’ll do two steps and watch what changes.

Step 1

Choose. Epsilon is 1.0, which is very high, so the mouse picks a random move. It goes right.

Act. It finds a small cheese. Reward is 1, and the mouse is in a new spot.

Update. The old number for that spot and move was 0. The new number is:

Q = 0 + 0.1 * (1 + 0.99 * 0 - 0) = 0.1

The best number in the next spot is still 0, because the table is empty. So the whole thing is just 0.1 times the reward. The table now knows that going right here is a little good.

Step 2

Choose. Epsilon dropped a tiny bit to 0.99, because we want less random moves as training goes on. It’s still high, so the mouse picks random again. This time it goes down, which is a bad move, because it leads straight to the poison.

Act. The mouse eats the poison. Reward is -10 and it dies.

Update.

Q = 0 + 0.1 * (-10 + 0.99 * 0 - 0) = -1

Now the table knows that going down from that spot is bad. Because the mouse died, a new episode starts.

What I noticed

After just two random steps, the table already isn’t blank. One cell is a little positive and another is negative. Before, everything was zero.

It also showed me why the learning rate matters. The reward was -10, but the number became -1, not -10. The agent doesn’t jump all the way to the new number. It moves one tenth of the way. It’s like not believing one bad experience completely, but also not ignoring it.

Keep doing this, exploring and then slowly trusting the table, and the numbers get better and better. At the end of training, the table is a good estimate of the best Q-function.
