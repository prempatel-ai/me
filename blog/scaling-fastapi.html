Scaling FastAPI & PostgreSQL for 10k+ Concurrent Users

Jan 20, 2026

Connection pooling, async batching, Redis read-through caching, and DB indexing lessons learned building CampusCircle by Prem Patel.

Live Demo | View Project in Portfolio

The Concurrency Wall

Building CampusCircle for real-time university community engagement meant preparing for sudden bursty traffic during campus elections and event announcements. Under load tests, naive synchronous database queries collapsed response latency past 1800ms.

Async Engine & PgBouncer Pooling

Switching SQLAlchemy to asyncpg and configuring PgBouncer connection multiplexing eliminated the per-connection memory overhead in PostgreSQL, reducing p99 latency down to 42ms under 8,000 requests/sec.

Two-Tier Cache Invalidation

Feed timelines and popular group listings are cached in Redis with probabilistic early expiration (XFetch) to prevent cache stampedes when hot keys expire. Write paths invalidate localized cache tags asynchronously via Redis Pub/Sub workers.
